# Portfólio "Now Playing"

Responda em português do Brasil.

Antes de qualquer mudança, leia `CONTEXTO.md`: ele traz as decisões de design, a stack, a regra de cores e formas e o que ainda falta fazer.

Para qualquer trabalho visual, siga a skill em `.claude/skills/taste-skill/SKILL.md` e rode o Pre-Flight Check (seção 14) antes de dar a mudança como pronta.

Conteúdo editável fica em `src/content/site.ts`. Não espalhe textos pelos componentes.

Comandos:
- `npm run dev` para desenvolver
- `npm run lint` e `npm run build` antes de concluir uma tarefa
