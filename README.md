# Portfólio "Now Playing"

Portfólio pessoal com tema de player de música: cards de vidro fosco, coverflow de projetos do GitHub e animações fluidas.

## Rodando

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Personalizando

Edite `src/content/site.ts` com seus dados. O passo a passo completo e as decisões de design estão em `CONTEXTO.md`.

## Build

```bash
npm run lint
npm run build
npm start
```
